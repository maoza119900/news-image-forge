## How it works

`entry.png` (1024×1024, ~141 KB) was rendered at build time by `render.py`
(Pillow + DejaVu fonts) and is shipped in the repo. The entry program,
`main.py` (Python 3.13, standard library only), copies it to
`$MAKEFUN_OUTPUT_DIR/entry.png` — byte for byte, so both grading runs
produce identical output. The program runs with no network.
